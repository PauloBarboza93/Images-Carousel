Desenvolvimento Front-End

Front-end é a parte de um site ou aplicativo com a qual a pessoa interage: o que ela vê na tela, os botões em que clica e os formulários que preenche. Quem trabalha com front-end transforma um design em uma página que funciona no navegador, se adapta a diferentes telas e é acessível a todos. A base desse trabalho são três tecnologias: HTML, CSS e JavaScript.

Os pilares do desenvolvimento Front-End

HTML5

HTML (HyperText Markup Language, linguagem de marcação de hipertexto) define a estrutura e o conteúdo de uma página: títulos, parágrafos, imagens, links, listas e formulários. Ele não é uma linguagem de programação: usa marcações, as tags, como <h1> e <p>, para dizer ao navegador o que cada parte do conteúdo é.

Criado por Tim Berners-Lee no início dos anos 1990, junto com a própria World Wide Web, o HTML passou por várias versões. O HTML5 virou recomendação oficial do W3C (World Wide Web Consortium) em 2014. Desde 2019, a especificação é mantida pelo WHATWG como um "padrão vivo", atualizado continuamente; por isso, hoje se fala apenas em HTML.

Entre as novidades do HTML5 estão as tags semânticas, como <header>, <nav>, <main>, <section> e <footer>, que deixam claro o papel de cada parte da página para navegadores, buscadores e leitores de tela; as tags <video> e <audio>, que tocam mídia sem plugins; e novos tipos de campo em formulários, como e-mail e data.

CSS3

CSS (Cascading Style Sheets, folhas de estilo em cascata) define a aparência da página: cores, fontes, espaçamentos, tamanhos e a posição de cada elemento. Separar a estrutura (HTML) da aparência (CSS) facilita a manutenção: o mesmo arquivo de estilo serve para várias páginas, e mudar uma regra muda o site inteiro.

O CSS foi proposto por Håkon Wium Lie em 1994, e o CSS nível 1 virou recomendação do W3C em 1996. Antes disso, a aparência era definida dentro do próprio HTML, com tags como <font>, hoje obsoletas. A partir do CSS3, a linguagem passou a ser dividida em módulos (cores, seletores, layout, animações), cada um evoluindo no seu ritmo.

O "cascata" do nome indica que várias regras podem valer para o mesmo elemento, e o navegador decide qual aplicar pela especificidade e pela ordem. Recursos como Flexbox, Grid e media queries permitem criar layouts responsivos, que se adaptam a celulares, tablets e computadores, como esta página.

JavaScript

JavaScript é a linguagem de programação que dá comportamento à página. Com ela, o site reage ao que a pessoa faz: um clique, uma tecla, o envio de um formulário. Nesta página, é o JavaScript que faz o carrossel trocar as imagens e o botão Pausar/Continuar funcionar.

Foi criado em 1995 por Brendan Eich, na Netscape, para o navegador Netscape Navigator. Apesar do nome, não tem relação direta com a linguagem Java. Sua versão padronizada se chama ECMAScript, mantida pela Ecma International; a edição de 2015 (ES6) trouxe recursos muito usados hoje, como let, const e as arrow functions, e desde então sai uma nova edição por ano.

Hoje o JavaScript roda em todos os navegadores modernos e também fora deles, em servidores (com Node.js) e aplicativos. Ele trabalha junto com o HTML e o CSS: pode ler e alterar o conteúdo e o estilo da página por meio do DOM (Document Object Model), a representação da página que o navegador cria na memória.
